# Documentation

This repository keeps the public documentation focused on the engineering content that can be inspected directly in the source code.

## Core DSA

- Custom Hash Table with separate chaining and dynamic resizing
- Binary Min-Heap Priority Queue
- 2-D seat array
- Linear, Binary and Hash Search
- Merge Sort and Bubble Sort
- Benchmarking and KPI collection

The original academic report and presentation are kept outside the public repository because they contain student identification numbers.
